> **Sicherheitshinweis:** Das Setup dieser Version startet Hilfsprogramme von Windows ohne vollen Pfad. Liegt im selben Ordner wie die Setup-Datei, etwa unter „Downloads", ein Programm namens `cmd.exe`, `tasklist.exe`, `find.exe` oder `taskkill.exe`, führt das Setup es aus ([GHSA-mgf2-2f98-ff87](https://github.com/Celestial0579/WidgetTea/security/advisories/GHSA-mgf2-2f98-ff87)). Behoben in [WidgetTea 1.1.0](https://github.com/Celestial0579/WidgetTea/releases/tag/v1.1.0). Für neue Installationen bitte 1.1.0 verwenden. Ein installiertes 1.0.0 holt sich das Update selbst; die Datei bleibt hier nur zum Nachvollziehen.
